# Portafolio Web - Curriculum Vitae

Proyecto de Curriculum Vitae web desarrollado con **HTML, CSS y JavaScript**.  
El sitio presenta información personal, educación, clubs, proyectos, habilidades, formulario de contacto y un mapa interactivo.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- Google Fonts
- Devicon

## Estructura del proyecto

```text
.
├── index.html
├── stylesheets/
│   ├── style.css
│   └── map.css
├── javascript/
│   ├── typing-effect.js
│   ├── map.js
│   └── menu.js
├── img/
│   ├── profile.jpg
│   ├── logo_niot.png
│   ├── Nu Zeta Logos09.png
│   ├── ciap-logo.png
│   ├── pre-ciap_project.png
│   └── nasa-spaceapps_project.png
└── README.md
```
## Características
- Diseño responsivo.
- Estructura semántica con HTML5.
- Diseño por columnas usando Flexbox y Grid.
- Formulario de contacto.
- Mapa interactivo con Leaflet.
- Estilos personalizados con CSS.
